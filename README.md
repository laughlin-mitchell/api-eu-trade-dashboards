# API EU trade dashboards

Public pages from Animal Policy International's EU trade dashboards, built from Eurostat international trade in goods data (Comext DS-045409).

| Page | Folder | On the API website |
|---|---|---|
| EU egg trade dashboard | [`egg/`](egg/) | [EU egg imports dashboard](https://www.animalpolicyinternational.org/eu-egg-imports-dashboard) |

- The pages are generated by the monthly pipeline on each Eurostat release day, and published only after that run's QA checks pass. Don't edit them by hand: the next run overwrites them.
- [`publish_log.md`](publish_log.md) lists every publish: date, page, data period and QA result.
- Each commit is one publish, so the commit history is the version history.
- Netlify sites linked to this repo serve the pages, and the API website embeds them.
